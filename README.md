A deterministic Node 22 program that writes one dad joke of at most 140
characters to `/output/entry.txt`. It uses only the standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, output goes to `/output/entry.txt`.
Candidate scoring and refinement are documented in `CANDIDATES.md`.
